# blackswan

Downloads for blackswan, the self-hostable cloud on one box. This repository holds releases only.

- **Mac app** (Apple silicon, macOS 26): [blackswan.dmg](https://github.com/agentbird-sh/blackswan-releases/releases/latest/download/blackswan.dmg)
- **Canary**, built from the newest code twice a day: [blackswan-canary.dmg](https://github.com/agentbird-sh/blackswan-releases/releases/download/canary/blackswan-canary.dmg)
- **CLI** for macOS and Linux: `curl -fsSL https://github.com/agentbird-sh/blackswan-releases/releases/download/cli-latest/install.sh | sh`

Every file has its sha256 beside it.
